# Desktop: анализ услуг ТО компьютерной техники

PyQt6-клиент к backend. Повторяет веб-интерфейс: текст, визуал, парсинг страницы, дерево ссылок, история запросов.

## Запуск

Сначала backend из корня проекта:

```bash
python run.py
```

Затем:

```bash
cd desktop
python main.py
```

Логи клиента: `logs/desktop.log` (в корне репозитория).

## Сборка .exe

```bash
cd desktop
python build.py
```

Файл: `dist/CompServiceMonitor.exe`. Backend по-прежнему запускается отдельно.

Очистка артефактов: `python build.py clean`.

## Функции

- Анализ описания услуг ТО (прайс, КП, договор)
- Анализ визуала (прайс, баннер, фото сервиса)
- Парсинг **одной** указанной страницы (не всего сайта)
- Сбор внутренних ссылок с текущей страницы и сохранение в `.config`
- Вкладка **Сайты**: иерархическое дерево ссылок
  - зелёный статус / отмеченный чекбокс — страница уже проанализирована
  - чекбокс выбора + «Парсить выбранные» — ручной разбор отмеченных URL по очереди
- Выпадающий список сохранённых URL на вкладке парсинга (`✓` = уже разобрана, отступ = уровень в дереве)
- История последних 10 запросов анализа (`history.json`, отдельно от дерева ссылок)

Сборка `.exe` не включает backend: для дерева ссылок и парсинга сервер должен быть запущен (`python run.py`).
